# Folder Audio Musik Latar ("Background Music")

Kamu bisa meletakkan lagu romantis favorit kalian di folder ini dengan nama:
- `bg-music.mp3`

Catatan:
Jika file MP3 belum dimasukkan, website sudah dilengkapi dengan Web Audio API Synthesizer bawaan yang secara otomatis memainkan melodi lembut kotak musik romantis!
Begitu file `bg-music.mp3` ditaruh di sini, website akan otomatis memutar lagu MP3 tersebut.
